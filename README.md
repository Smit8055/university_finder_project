# University Finder – Web Version (Streamlit)

This is a **browser-based Python app** to help students search and shortlist universities based on country, tuition fees, and application deadlines. Built with **Streamlit**, the project features an interactive interface with smart timelines and customizable filters.

It is a modern, accessible version of a desktop app originally built using Tkinter.

---

## 🌐 Live Use (Optional)

Once deployed (e.g., using [Streamlit Cloud](https://streamlit.io/cloud)), this app runs fully in the browser with **no need to download or install anything**.

---

## 🎯 Features

- Search universities by country
- View tuition fees and deadlines
- Auto-generated application timeline:
  - Start research
  - Prepare documents
  - Submit application
- User-friendly interface with expandable views
- Optional saving/export feature (in original desktop version)

---

## 🧪 Technologies Used

- Python 3.7+
- Streamlit
- datetime module
